The roadmap

Top to bottom, project 01 first

Phase 1 Foundations
01 First Predictive Model Train and score a regression model end to end on a small tabular dataset. 02 Linear Algebra from Scratch Write matrix operations, least squares, and PCA in NumPy without a library solver.
Phase 2 Core ML
03 Text Classification Turn raw text into features and compare a linear baseline against a neural model. 04 Clustering with Eigenvectors Build spectral clustering on a graph and check it against k-means.
Phase 3 Vision
05 Image Classification Train a small CNN, then fine-tune a pretrained backbone and compare the two. 06 Scanned Document Classifier Read scanned pages with OCR and sort them by layout and text together. 07 Facial Emotion Recognition Detect faces, classify expressions, and handle a class-imbalanced dataset.
Phase 4 Finance
08 Market Time-Series Forecasting Backtest price forecasts with walk-forward validation instead of a random split. 09 Credit Default Prediction Score risk with gradient boosting and explain each decision with SHAP values. 10 Financial Data Pipeline Schedule ingestion, validation, and storage so the data refreshes on its own.
Phase 5 LLMs and Agents
11 Document Assistant (RAG) Answer questions over a large document collection of your choice with retrieval, and cite the source passage. 12 Autonomous Research Agent Give a model tools, memory, and a plan loop, then have it write up its findings.
